ISHITA'S BIRTHDAY SURPRISE WEBSITE 💗

UPDATED RIBBON OPENING
- Decorative satin ribbon and bow over the birthday gift screen.
- Drag the bow/ribbon down with a finger on mobile or mouse on desktop.
- Tap the opening button as an accessible alternative.
- On opening, the Happy Birthday melody is started via the visitor's interaction (browser audio policies may vary).
- Responsive ribbon, gift box and music dock for small screens.

FEATURES
- 9 optimized personal photos in the gallery
- Friendship-to-love animated mini movie
- Floating hearts, star effects and scroll reveals
- Animated birthday cake and final surprise message
- Romantic and Happy Birthday synthesized melodies with controls

PREVIEW
Open index.html in Chrome or another modern browser.

DEPLOY
Upload this folder to GitHub and import it into Vercel. Static HTML/CSS/JavaScript; no build command is required.
